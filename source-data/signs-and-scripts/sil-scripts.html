Special script categories

Section titled “Special script categories”

These are not actual scripts but are special codes for other uses.

  • Reserved for private use (start) [Qaaa]
  • Reserved for private use (end) [Qabx]
  • Inherited script [Zinh]
  • Mathematical notation [Zmth]
  • Symbols (Emoji variant) [Zsye]
  • Symbols [Zsym]
  • Unwritten documents [Zxxx]
  • Undetermined script [Zyyy]
  • Unencoded script [Zzzz]
